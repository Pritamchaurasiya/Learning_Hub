### 🐳 Beyond Single-Node Docker Compose

While Docker Compose coordinates local services, production enterprise infrastructure requires:

1. **Zero-Downtime Rolling Updates**: Traffic smoothly migrates from version $N$ pods to version $N+1$ without dropping a single TCP connection (`maxSurge: 25%`, `maxUnavailable: 0`).
2. **Horizontal Pod Autoscaling (HPA)**: Dynamically scales from 3 to 10 replicas when CPU or request saturation crosses 80%.
3. **Self-Healing Probes**:
   - `readinessProbe` on `/api/v1/health/ready`: Confirms DB & Redis connectivity before routing live traffic.
   - `livenessProbe` on `/api/v1/health/live`: Automatically restarts deadlocked worker threads.

### ⛑️ Helm Chart Architecture (`charts/learning-hub/`)

- `Chart.yaml`: Application versioning & metadata.
- `values.yaml`: Configurable production environments (Dev, Staging, Prod).
- `templates/`:
  - `deployment.yaml`: Django Web ASGI workers (Daphne/Gunicorn).
  - `worker-deployment.yaml`: Celery background workers.
  - `service.yaml`: Internal ClusterIP load balancer.
  - `ingress.yaml`: TLS-terminated Nginx Ingress with cert-manager Let's Encrypt certificates.
  - `hpa.yaml`: Horizontal Pod Autoscaler.
